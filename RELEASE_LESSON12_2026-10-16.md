# Norsk Eventyr 8.3.0-lesson12 — релизная приёмка, 16.10.2026

**Цель:** подготовить дополнительную практику заполнения учебных документов и грамматики к выпуску, сохранив работающую версию 8.3.0 и возможность отката.

**Исходники:** `feature/applied-forms-cloze-20261016`, GitHub PR #67; отдельная ветка, которая **не слита в `main`**. Этот документ не является разрешением на публикацию. Точный SHA кандидата берётся из последнего успешного GitHub Actions QA, а не из старых отчётов.

## Реализованный объём

- 8 самостоятельно созданных **учебных имитаций** форм, по 2 на A1, A2, B1, B2. Это **не официальные** документы NAV, Skatteetaten или коммуны. Для упражнений используются только вымышленные данные.
- 32 упражнения (8 на уровень) по выбору и самостоятельному вводу правильной формы: presens, preteritum, perfektum, число, согласование, V2, пассив, условные конструкции.
- Автоматически оцениваются только строго определённые ответы: слово в пропуске и структурированные поля бланка. Открытый текст показывается с образцом, но **не оценивается автоматически**; процент по форме не является оценкой свободного письма.
- Отдельный раздел в «Ещё» и быстрые ссылки на главном экране; адаптивный мастеринг курса и нормативное подтверждение уровня не меняются.
- В сохраняемый локальный прогресс записываются дата, категория, сумма баллов и теги ошибок. Введённые персональные поля и тексты заявлений туда **не** записываются. Провести регрессию восстановления/облака и проверить отсутствие попадания текста в сеть.

## Автоматическая приёмка

- `tests/applied-practice.cjs`: структура всех 40 задач, точность ожидаемых ответов, сохранение, отсутствие персонального текста в результатах и CEFR-гейта.
- `tests/applied-browser.cjs`: реальный мобильный Chromium 390px, навигация, заполнение, проверка, ошибка и отсутствие горизонтальной прокрутки и JS-ошибок.
- Остальная обязательная `npm test` в `.github/workflows/qa.yml`: смоук предыдущих функций, курс, микрофон, безопасность, PWA.
- После **успешной** QA в GitHub Actions формируется архив исходников **точного проверенного SHA**: `Norsk-Eventyr-8.3.0-lesson12-release-candidate` (ZIP, SHA256SUMS и RELEASE_MANIFEST_8.3.0.json). Архив не развертывается на production.

Перед публикацией должны совпадать:
1. HEAD PR #67;
2. зелёный SHA GitHub QA;
3. SHA готового Vercel Preview;
4. SHA ZIP в манифесте.

## Ручная приёмка (НЕ ОТМЕЧАТЬ «ПРОЙДЕНО» БЕЗ РЕАЛЬНОГО ТЕСТА)

- [ ] На личном Android в Chrome войти в тестовый аккаунт на **Preview**; убедиться, что это не основной домен.
- [ ] Открыть главную страницу, «Ещё» → «Анкеты и заявления», выбрать A1, заполнить форму вымышленными данными, получить корректную обратную связь.
- [ ] Повторить форму B1 и B2 со свободным текстом; сравнить пример и убедиться, что он **не** выдаётся за официальную юридическую консультацию.
- [ ] В разделе «Вставить слово» пройти все 8 A1 и все 8 B2, включая неверный ответ, подсказку и повторение.
- [ ] Проверить удобство с клавиатурой телефона, прокрутку, ориентацию экрана и кнопку назад.
- [ ] Закрыть приложение в середине курса и открыть снова: старые завершённые уроки, XP, словарь и активный урок должны сохраниться.
- [ ] Проверить офлайн-подгрузку новой практики после первого онлайн-открытия, а также обновление PWA с предыдущей ревизии `lesson11`.
- [ ] Пройти хотя бы один старый урок: аудио/микрофон, прогресс, проверка навыков, не нарушена работа Норы.
- [ ] Проверить обычный аккаунт и отдельно аккаунт владельца: доступ закрытым пользователям, панель владельца недоступна обычным.
- [ ] Убедиться, что данные одного пользователя не видны другому, тексты из учебных форм не уходят в аналитику, ошибка доступа не открывает экран.

## Риски, которые нельзя закрыть только CI

Согласно `LIVE_RELEASE_READINESS_2026-10-13.md` и `AUDIT_REMEDIATION_2026-10-14.md`, на даты проверки остались открытыми: исторические RPC grants и план миграции, параметры Firewall/лимитов AI, настройка проверки скомпрометированных паролей, GDPR-сроки хранения/удаления, независимая проверка материалов, полевая приёмка микрофона Android. Нужна **новая фактическая проверка** перед публичным релизом; старые выводы нельзя принимать за неизменную текущую конфигурацию. Нельзя выполнять SQL cutover без резервной копии, испытания и отдельного разрешения владельца.

**GO для ограниченного внутреннего теста:** зелёный QA + READY Preview на одном SHA, пройдены Android-сценарии новой практики и ключевые регрессии, нет утечки/потери данных.

**NO-GO для массового публичного расширения:** пока не закрыты актуальные вопросы безопасности/приватности/приёмки и нет разрешения владельца.
