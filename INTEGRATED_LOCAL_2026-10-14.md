# Norsk Eventyr 8.3.0 — объединённая локальная сборка (14.10.2026)

**Статус:** только интеграционная ветка, без слияния в `main` и без обновления Production.

## Состав

1. PR #59: оригинальная методическая структура 32 тематических модулей A1–B2, четыре этапа работы, план 60 минут × 6 дней, маршрутизация в преподавателе и AI-генераторе, схема часов и ограничений.
2. PR #58: интервальные повторения без ложного ускорения от нескольких правильных ответов в один день; отложенный правильный ответ продвигает интервал, ошибка приближает повторение.
3. Интеграция: обновлена версия ресурсов PWA `8.3.0-lesson5`, добавлены проверки, что обе функции работают в общем состоянии, и отдельная сборка ZIP исходников.

## Защита существующего

- `main`, production deployment, доступ, сохранения прогресса, Supabase, AI ключи и пользовательские данные не меняются.
- Изменения в исходниках применены поверх PR #59; функциональная часть PR #58 перенесена точечно в `adaptive-teacher.js` и `tests/adaptive-8.0.0.cjs`. Не копируются более старые версии PWA/assets из PR #58.
- Новый интеграционный тест проверяет сценарий курса и интервального повторения на одном состоянии ученика.
- Полная существующая серия тестов запускается в GitHub Actions для интеграционного PR.

## Локальный архив

При **успешной** QA GitHub Actions выполняет `node tools/prepare-staging-release.cjs --ref <exact-commit-sha>`.
Артефакт **Norsk-Eventyr-8.3.0-course-retention-local** содержит:
- `norsk-eventyr-8.3.0-source.zip` — репозиторий точно проверенного коммита, без `.git` и переменных окружения;
- `RELEASE_MANIFEST_8.3.0.json` — SHA коммита, число файлов и назначение сборки;
- `SHA256SUMS` — контрольная сумма архива.

Артефакт хранится GitHub Actions 14 дней. При упавшей QA ZIP не подготавливается и не загружается.
Сценарий архивирования ничего не публикует.

## Нельзя утверждать без независимых проверок

- Нет доказательства, что 600 часов достаточно для уровня B2 каждому человеку.
- Не проведена независимая вычитка полного корпуса и не подтверждены реальные аудиозаписи носителей.
- Автоматические проверки **не заменяют** полевые тесты Android с микрофоном, проверку реальных пользователей и внешний экзамен Norskprøven.
- PR #58 и PR #59 оставлены отдельными черновиками. Этот интеграционный PR — единственный новый объединённый кандидат, но он тоже черновик, без одобрения публикации.
