# Аудио для урока «Знакомство»

Девять локальных MP3 с синтетическим произношением Bokmål. Источник — eSpeak NG 1.51, голос `nb`, скорость 135 слов в минуту. Норвежские тексты соответствуют заданиям в `introductions.js`. Для перекодирования WAV в MP3 использовался FFmpeg. При воспроизведении урок запрашивает файлы только со своего сайта.
