## Техническая сборка
После успешного GitHub Actions QA для этой ветки `.github/workflows/qa.yml` вызывает:
`node tools/prepare-staging-release.cjs --ref "$NE_RELEASE_REF"`
c `NE_RELEASE_REF`, установленным в **SHA текущего PR**. Создаётся артефакт **Norsk-Eventyr-8.3.0-lesson24-release-candidate** с:
- `norsk-eventyr-8.3.0-source.zip` — архив исходников точного коммита;
- `RELEASE_MANIFEST_8.3.0.json` — версия, источник, флаги «не опубликовано», SHA-256, сведения о корпусе;
- `SHA256SUMS` — контрольная сумма.

**Проверка перед публикацией:** SHA заголовка PR == SHA завершённого успешно QA == `sourceCommit` в манифесте. SHA-256 ZIP == запись в `SHA256SUMS`. Доказательств реального Android/производственного окружения автоматическая сборка не даёт.
