# Norsk Eventyr 8.2.5 — исправление ожидания озвучки (черновик, без публикации)

## Причина
В 8.2.4 интерфейс ожидал целиком сформированный WAV от `/api/speech`. У клиентского запроса и серверного обращения к провайдеру не было предельного времени ожидания. Кнопка «Готовлю голос…» могла оставаться в этом состоянии длительное время.

## Изменения
- Единый `speakText()` обрабатывает диагностику, уроки, словарь, разговоры, тренировочные экзамены и другие функции озвучки.
- При наличии норвежского голоса на устройстве воспроизведение начинается непосредственно по нажатию; приоритет у Bokmål (`nb-NO`).
- Если локальный голос недоступен, используется AI MP3. Запрос отменяется через 4 секунды, после чего запускается синтезатор браузера с языком `nb-NO`.
- Ограничено ожидание запуска проигрывателя; при ошибке декодирования используется резервный синтезатор.
- Подготовка аудио откладывается на 350 мс; повторные одинаковые запросы используют общую задачу и кеш из 12 элементов. После сетевой ошибки применяется двадцатисекундный период без повторных запросов.
- `/api/speech`: MP3 вместо WAV, серверный тайм-аут 8,5 секунды, корректные коды ошибки.
- `apiPost` поддерживает `AbortSignal`, включая обновление сессии при HTTP 401.
- Версии файлов и кеша повышены до 8.2.5 для корректного обновления установленного PWA.

## Проверено
- Синтаксис клиентского JavaScript: проверен в JS-парсере.
- Модульные проверки `tests/tts-fast-8.2.5.cjs`: пройдены в изолированной JS-среде: норвежский голос, аварийный переход при тайм-ауте, объединение предварительной загрузки и воспроизведения, отмена старого воспроизведения.
- Изменения сохранены только в ветке `fix/fast-audio-8-2-5-20261012`; `main` не изменён.

## Остаётся перед публикацией
- Полный `npm test` (включая Playwright) ещё не запускался в CI для этой ветки; в реальном Android Chrome звук не проверялся.
- Устройство без норвежского голоса может использовать системный голос с менее точным произношением, чем AI. Без установленной поддержки речи невозможно гарантировать мгновенный запуск.
- В случае недоступного или слишком медленного AI-сервиса сохранён резервный путь; реальная скорость зависит от устройства, сети и провайдера.
- Не сливать в `main` и не публиковать без отдельного разрешения владельца.
