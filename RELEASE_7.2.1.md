# Norsk Eventyr 7.2.1

Единый выпуск исправлений после аудита 7.2 и безопасного обновления приложения у пользователей. Публикация разрешена пользователем 03.10.2026. База: 0990ad4.

## Исправления

- Повторные отправки и повторное начисление результата в уроках, тестах, домашнем задании, сюжетных сценах и экзаменационных частях.
- Запоздалые ответы ИИ и генерация материалов больше не перехватывают выбранную пользователем вкладку.
- Повреждённые резервные копии отклоняются до изменения данных; перед восстановлением и сбросом сохраняется предыдущий прогресс. Сброс заново инициализирует все слои и отключает облако данного устройства.
- Ошибка записи при переполненном локальном хранилище не останавливает приложение и сопровождается сообщением.
- Проверка структуры заданий ИИ отклоняет пустые варианты и неверные индексы ответа.
- Облачное объединение сохраняет отдельные коллекции избранного, бесед, памяти и тренировок. Параллельные синхронизации блокируются, отказ сохранения не сообщается как успех, неправильный новый код не удаляет прежнюю связь.

## Обновления у пользователей

Приложение проверяет новую версию при открытии, возвращении на вкладку, подключении к сети и раз в 15 минут. Когда версия готова, показывает «Обновить приложение». Кнопка откладывает обновление во время упражнения, записи или при наличии введённого текста. Перед перезагрузкой сохраняется прогресс. Версионированные адреса JS/CSS предотвращают загрузку прежнего кода из старого кеша. Обновление программы не объединяет личные данные пользователей.

Для уже установленной 7.2 нужно один раз открыть или обновить приложение с интернетом, чтобы загрузился новый механизм. Следующие версии обнаруживаются внутри приложения. Без сети действует сохранённая версия.

## Проверки

- JavaScript syntax и git diff --check.
- 20 разделов без пустого интерфейса и горизонтального переполнения.
- Основные уроки A1–B2 и 12 экранов на ширинах 360, 390, 768 px.
- Повторные отправки, запоздавшие ответы, восемь повреждённых копий, переполненное хранилище, импорт с резервной копией и сброс.
- Клиентская синхронизация с тестовыми RPC: сохранение коллекций, один pull/push, отказ записи, сохранение прежнего подключения.
- 18 некорректных ответов ИИ отклонены и три корректных формата API приняты.
- Настоящий service worker в Chromium: переход с опубликованной 7.2 на 7.2.1, отдельный прогресс двух профилей, блокировка обновления во время задания, обнаружение следующего выпуска и работа после перезагрузки без сети.

Повторяемые проверки сохранены в tests. Установить зависимости в tests, затем npm test. Для нестандартного Chromium используется NE_CHROMIUM_PATH.

## Ограничения

Ответы ИИ, облачные RPC и устройства ввода в локальных тестах имитируются. Реальная синхронизация двух телефонов, микрофон Android, качество всех ответов ИИ и массовая нагрузка не подтверждены. При совпадении ключей облачное объединение сохраняет локальный вариант; полноценного разрешения конфликтов одной и той же беседы нет. Обнаружение версии у всех пользователей требует интернета и открытия приложения. Проверки не гарантируют отсутствия всех возможных ошибок.

Локальную копию неопубликованного аудита удалило обслуживание среды. Изменения заново восстановлены по истории проверки поверх опубликованного кода и протестированы перед этим выпуском.
