# Norsk Eventyr 8.3.0 — личный тестовый Android APK

Эта папка собирает **только тестовый APK** для установки напрямую на Android.
**Это не Google Play-релиз, не автономная офлайн-программа и не подписанное магазинным ключом приложение.**

- APK открывает только специальный **предварительный адрес релизного кандидата 8.3 RC** на Vercel и разрешает микрофон для изучения языка (после согласия владельца телефона).
- Все учебные данные, вход и AI работают через сетевой сайт. Без интернета функциональность ограничена.
- Для работы **необходим доступ к Vercel Preview**. Если его защита требует вход или возвращает 403, APK может открывать страницу доступа вместо Norsk Eventyr. Это нужно проверить на реальном телефоне перед заявлением о готовности.
- В Android WebView нельзя автоматически считать проверенными все функции браузера: отдельно проверьте микрофон, звук, восстановление прогресса, внешний вход по почте, импорт/экспорт и обновления.
- Debug-подпись временная; после смены подписывающего ключа для установки следующей сборки может понадобиться удалить прежний тестовый APK. Перед этим сохраните резервную копию прогресса.
- Не вводите реальные платёжные данные и не принимайте эту сборку за приложение из Google Play.

## Сборка

GitHub Actions **Norsk Eventyr 8.3 private APK** собирает APK в Pull Request и прикрепляет его к запуску CI как временный артефакт (7 дней). 
Gradle 8.13, Android SDK 36 и JDK 17:

```bash
gradle -p android-test assembleDebug "-PnorskUrl=https://norsk-eventyr-no7xsypvy-fffff19.vercel.app/"
```

По умолчанию сборка намеренно **отклоняется**, если адрес не передан или не относится к конкретному RC Preview. Текущий Production не должен использоваться для тестирования изменений. Важно: сборка доказывает только компиляцию оболочки, а не наличие на Preview именно последнего коммита. Перед установкой сверить в Vercel SHA Preview с SHA проверенной ветки; устаревший Preview означает запрет выпуска.

Перед возможным Google Play потребуется отдельный коммерческий, юридический, платёжный и технический аудит, полноценное Android-тестирование и разрешение владельца.

## Привязка к проверенному веб-релизу 8.3.0
APK открывает неизменяемую Vercel Preview, соответствующую коммиту `6b0165fa659fb347363b74ac707abffb5a69a4b1`, который прошёл GitHub QA. Последующие изменения staging PR, связанные только с Android-оболочкой и документами, не должны менять веб-код. CI проверяет отсутствие изменений в соответствующих runtime-файлах; если они изменятся, требуется новая Preview/SHA и пересборка.

**Отличие от Chrome:** WebView имеет собственные cookies и хранилище. Перед установкой/удалением APK сделайте экспорт прогресса; нельзя обещать автоматический перенос локальных данных Chrome. Подтвердите вход, звук, запись голоса и экспорт в настоящем APK. APK не является магазинной сборкой; при различной debug-подписи Android может потребовать удалить старую тестовую версию — только после резервного копирования. Не устанавливать APK из неизвестных источников или пересылать его незнакомым людям.
