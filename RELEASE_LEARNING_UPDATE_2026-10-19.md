# Norsk Eventyr 8.3.0 — learning update release candidate

Дата: 2026-10-19. Ветка: `release/8.3.0-learning-update-20261019`. Исходная основа: проверенные исправления draft PR #81, SHA `8ec8742a32197d00068d3e37122bde7d75fe0e6a`. **Кандидат НЕ опубликован и не слит в main.**

## Что входит
- Понятные упражнения по модальному `kunne`, разъяснение `kan / kunne` и действие «Объяснить задание» без ошибочного штрафа за подсказку.
- После двух неверных попыток — подробный разбор подготовленного задания и новая ситуация. Показ образца не засчитывает знание, не снимает ошибку из повторения.
- Если нет подтверждённого примера, не придумываем его.
- Исправление преждевременных отказов морфологического фильтра для `har alltid kunnet`, `skal jeg kanskje kunne` и подобных ограниченных конструкций. Семантику проверяет Нора, нет автоматического зачёта только по форме.
- Открытый аудит реальных публичных обсуждений и ограничения: `AUDIT_REAL_USER_REVIEWS_2026-10-19.md`, `AUDIT_LEARNING_CLARITY_2026-10-19.md`.

## Согласованная ревизия мобильной PWA
Старая ревизия: `8.3.0-lesson23-listening1-translate2`. Новая: `8.3.0-lesson23-listening1-translate3`.

- `index.html` подключает `access.js` с новой ревизией.
- `access.js` загружает **все три изменённые учебные модуля** (`card-grammar.js`, `card-form-practice.js`, `living-words.js`) с новым суффиксом `-translate3`.
- `sw.js` меняет имя кеша и предзагружает те же URL учебных модулей; старые PWA-кеши очищаются стандартной логикой активации. Остальные учебные модули, аккаунты, словарь, серверные API, SQL и пользовательский прогресс НЕ изменены.
- Контракт `tests/release-regression-gates.cjs` проверяет соответствие ссылок и запрет кеширования AI API.
