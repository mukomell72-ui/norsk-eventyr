# Norsk Eventyr — аудит стабильности и качества, 13 октября 2026

**Базовая опубликованная версия:** 8.2.9 (main).
**Подготовка проверок:** PR #50, `quality/regression-gates-20261013`.
**Статус:** проверка процесса разработки; **не публикация новой версии приложения**.

## Цель и пределы

Цель — уменьшить вероятность регрессий при исправлении задач A1–B2, речи, звука,
авторизации, сохранения прогресса и PWA. Абсолютную безошибочность гарантировать нельзя.
Автоматические тесты **не** заменяют испытания Android-устройства, реальных внешних
сервисов и независимое лингвистическое рецензирование.

## Найденные риски и действия

**P1 — нестабильный браузерный прогон.** В CI для PR #49 на первом запуске
`tests/browser.cjs` получил `ReferenceError: state is not defined` после проверки
ежедневного задания/побочной миссии (run 38364265418, attempt 1).
При повторе тот же набор тестов прошёл (attempt 2).
Причина не локализована; нельзя считать успешный повтор доказательством отсутствия
сбоя. Требуется дополнительная инструментальная диагностика внезапных перезагрузок,
времени авторизации и исчезновения состояния приложения.

**P1 — недостаточность аппаратных/педагогических свидетельств.** Нет подтверждения,
что всё распознавание и озвучка работают на каждом телефоне или что задания и оценка
ответов соответствует критериям Norskprøven. Для заявлений об уровне B1–B2 необходимы
слепые работы реальных учеников и экспертная проверка.

**P2 — PWA зависит от полноты списка предзагрузки.** `cache.addAll(ASSETS)`
может сорвать установку нового SW из-за одного отсутствующего ресурса. Новый
release gate проверяет пути и версии на каждом PR, но сетевые ошибки в продакшене
по-прежнему требуют отдельного контроля.

**P2 — перевод по запросу реализован точечно.** Для A1 «Где находится ключ?»
механика согласована с пожеланием пользователя. Правило на уровне всего курса
следует проектировать и тестировать отдельно, чтобы не убрать нужный перевод
новичкам из контекста объяснений и словаря.

**P2 — ручное разрешение публикации.** Любое слияние с `main` запускает
production deployment Vercel. PR #50 намеренно не сливается без отдельного
согласия владельца. Возможность защищать `main` правилами GitHub
нужно проверить с достаточными правами; текущий процесс полагается на
дисциплину отдельных веток.

## Выполненные изменения в PR #50

1. Добавлен `tests/release-regression-gates.cjs`, включён в обязательный
   `npm test` **перед** остальными тестами. Проверяются ссылки на ресурсы,
   общая версия выпуска, порядок загрузки скриптов, обход API в SW, содержание
   и ключи 32 модулей, наличие защит речи и перевода.
2. Добавлен реальный сценарий Chromium в `tests/browser.cjs` для перевода
   по запросу и сохранения набранного текста после открытия/закрытия подсказки.
3. Не менялись озвучка, микрофон, алгоритм обучения, бизнес-логика,
   публичный интерфейс или версия Production.

## Рекомендованный следующий этап

Перед функциональным обновлением проверять: базовые сценарии всех уровней,
переходы между этапами, ввод ответа без потерь, ручное предоставление перевода,
работу после обновления PWA, версионирование контента, доступ и восстановление
прогресса. Исправлять выявленные дефекты отдельными узкими PR;
публиковать только после разрешения владельца.

**Важно:** число успешных тестов — не процент качества обучения и не гарантия
работоспособности на телефоне. Этот аудит укрепляет предотвращение регрессий,
но не является независимой сертификацией программы.
